## Abstract

Computer system performance evaluation faces the challenge of analyzing long-running, complex workloads in simulation. Existing approaches often require re-simulation for each new system configuration, consuming significant computational resources. This work introduces **Nugget**, an LLVM IR-based sampling framework that turns long-running workloads into portable program snippets ("nuggets") which can be analyzed once, then reused across binaries, ISAs, and microarchitectures.

## Key Contributions

1. **Portable Sampling Framework**: Replaces simulator-based interval analysis with compiler instrumentation on real hardware, cutting sampling overhead by up to hundreds× versus functional simulation

2. **Binary and ISA Independence**: Keeps intervals binary-independent via an IR-level unit of work, enabling cross-ISA simulation and reuse across different microarchitectures

3. **Validation and Diagnostics**: Uses large SPEC CPU2017, NPB, and LSMS workloads to demonstrate how Nugget enables fast hardware-based validation of sampling methods and helps diagnose simulator modeling errors in gem5's Arm memory system

## Research Impact

This work significantly improves the efficiency of computer architecture research by enabling researchers to:
- Quickly validate sampling methodologies on real hardware
- Identify and diagnose simulator inaccuracies
- Reduce simulation time for performance evaluation studies
